# 费马点与最短管线问题：三顶点张角 120° 的最短连线模型

## 一、生活中的“供暖主管线规划”

假设在平原上有三个互不相邻的村庄 $A, B, C$，现在政府准备出资修建一个中央供暖加压站 $P$，并从 $P$ 分别向三个村庄铺设地下输暖管线 $PA, PB, PC$。

施工管道每米造价昂贵，如何选择中央站点 $P$ 的位置，才能使**三段管道总长度 $PA + PB + PC$ 达到绝对最小值**？

这就是 1643 年法国业余数学家之王皮埃尔·德·费马（Pierre de Fermat）在一封致托里拆利的信件中留下的旷世几何极值难题——**费马点问题（Fermat Point Problem）**！

---

## 二、费马点的核心几何特征

当 $\triangle ABC$ 的每一个内角都小于 $120^\circ$ 时：
1. **张角等分律**：使得 $PA + PB + PC$ 最小的点 $P$（费马点），其对三角形三条边的视角全部相等：
   $$\angle APB = \angle BPC = \angle CPA = 120^\circ$$
   （恰好将圆周角 $360^\circ$ 三等分，力学平衡状态）！

2. **钝角特例（$\ge 120^\circ$）**：
   如果三角形中有一个内角大于或等于 $120^\circ$（例如 $\angle A \ge 120^\circ$），那么费马点直接退化至该钝角顶点处：
   $$P \equiv A$$
   最小距离即为两边之和 $AB + AC$。

---

## 三、神级证明：旋转 60° 折线变直尺

如何严格证明当三张角为 $120^\circ$ 时，管道总长最短？意大利物理学家兼数学家托里拆利（Evangelista Torricelli）用**刚体平面旋转法**给出了宛如神迹的证明：

```
          A'
         / \
        /   \
       /  P' \
      /    \  \
     B------A--\
      \    / \  \
       \  P   \  \
        \/_____\__\
        B       C
```

### 1. 巧妙旋转变换
- 将 $\triangle ABP$ 绕着顶点 $B$ 逆时针旋转 $60^\circ$，得到 $\triangle C'BP'$（或以 $B$ 为中心把点 $P$ 旋转 $60^\circ$ 到 $P'$，把点 $A$ 旋转到 $A'$）。
- 因为旋转角为 $60^\circ$，且 $BP = BP'$，所以 $\triangle BPP'$ 是一个**等边正三角形**！
- 因此：
  $$PP' = BP$$
- 根据全等变换，线段 $A'P' = AP$！

### 2. 管道总长度的几何转化
原来的三段管线之和：
$$PA + PB + PC = A'P' + P'P + PC$$
注意观察右边这一串折线：**$A' \to P' \to P \to C$**！
- 起点是固定的点 $A'$（由点 $A$ 绕 $B$ 旋转 $60^\circ$ 确定，它是以 $AB$ 为边向外作的正三角形的第三个顶点）；
- 终点是固定的点 $C$；
- 中间经过了动点 $P'$ 和 $P$！

### 3. 两点之间，线段最短！
由公理“两点之间线段最短”，折线 $A'-P'-P-C$ 的长度大于等于两端点的直线距离：
$$A'P' + P'P + PC \ge A'C$$
**只有当 $A', P', P, C$ 四个点共线（连成同一条笔直的线段）时，等号才成立，总距离取得绝对最小值 $A'C$！**

### 4. 120° 角度的诞生
当四点在一条直线上时：
- 在等边三角形 $\triangle BPP'$ 中，$\angle BPP' = 60^\circ$；
- 因为 $C-P-P'$ 在同一直线上，所以外角补角：
  $$\angle BPC = 180^\circ - \angle BPP' = 180^\circ - 60^\circ = 120^\circ$$！
- 同理可得 $\angle APB = 120^\circ, \angle APC = 120^\circ$！
- 绝妙的旋转，将极其复杂的多元三维极值，化为一条笔直的连线！

## 四、托里拆利尺规作图法

如何在纸上快速精确找到费马点 $P$？
1. 分别以 $\triangle ABC$ 的三条边 $BC, CA, AB$ 为底边，向三角形外部各作一个**等边正三角形** $\triangle BCA', \triangle CAB', \triangle ABC'$；
2. 连接各正三角形的对顶点：$AA', BB', CC'$；
3. 这三条直线**必交于同一点**，这个交点正是费马点 $P$！
4. 并且这三条连线的长度全部相等，且正好等于最小管道总长：
   $$AA' = BB' = CC' = PA + PB + PC$$！

## 五、经典例题解析

### 例题一：正三角形内的费马点
> **题目**：边长为 $6$ 的等边三角形 $\triangle ABC$ 中，点 $P$ 是其费马点。求 $PA + PB + PC$ 的最小值。
>
> **解析**：
> 1. 等边三角形三内角均为 $60^\circ < 120^\circ$。
> 2. 由高度对称性，费马点 $P$ 恰好与等边三角形的中心（重心/外心/内心）重合。
> 3. 每个角平分线分割出的角度为 $30^\circ$，$\angle APB = 180^\circ - 30^\circ - 30^\circ = 120^\circ$，完全契合费马点定义！
> 4. 等边三角形的高为 $h = 6 \times \frac{\sqrt{3}}{2} = 3\sqrt{3}$。
> 5. 中心到顶点的距离 $R = \frac{2}{3} h = 2\sqrt{3}$。
> 6. 所以最小总距离：
>    $$PA + PB + PC = 3 \times 2\sqrt{3} = 6\sqrt{3} \approx 10.392$$。

---

### 例题二：钝角三角形的避坑考点
> **题目**：$\triangle ABC$ 中，$AB = 5, AC = 6, \angle BAC = 135^\circ$。在平面内找一点 $P$，使得 $PA + PB + PC$ 最小，求此最小值。
>
> **解析**：
> 1. 审题发现：$\angle BAC = 135^\circ \ge 120^\circ$！
> 2. 当三角形存在大于等于 $120^\circ$ 的钝角时，费马点位于**钝角顶点自身**（$P \equiv A$）！
> 3. 此时：$PA = 0$，$PB = AB = 5$，$PC = AC = 6$。
> 4. 最小总距离直接等于：
>    $$PA + PB + PC = 0 + 5 + 6 = 11$$！
>    （若强行在内部找 120° 点，算出的距离反而大于 11）。
