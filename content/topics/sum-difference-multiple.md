## 经典痛点：为什么孩子总在加差与减差之间抓阄？

小学三年级是孩子应用题思维建立的“黄金分水岭”。很多孩子在这个阶段开始掉队，最典型的就是遇到这三类题：

1. **和差问题：** “两人一共有 50 本书，小明比小红多 10 本，各几本？”
2. **和倍问题：** “两人一共有 60 本书，小明的书是小红的 3 倍，各几本？”
3. **差倍问题：** “小明的书是小红的 4 倍，小明比小红多 27 本，各几本？”

很多家长习惯性地让孩子死记硬背三套公式：
- $\text{大数} = (\text{和} + \text{差}) \div 2$
- $\text{小数} = (\text{和} - \text{差}) \div 2$
- $\text{小数} = \text{和} \div (\text{倍数} + 1)$
- $\text{小数} = \text{差} \div (\text{倍数} - 1)$

结果到了考场上，孩子脑子里全是各种符号在打架：“到底该加 1 还是减 1？到底谁除以 2？”  
根本原因只有一个：**孩子在脑子里没有线段图，看不到“削平”与“填齐”的几何过程！**

## 核心图景一：和差问题（去差法与补差法）

解决和差问题，新加坡数学（Singapore Bar Model）提供了世界上最优雅的直观方法——**让两条线段变得一般齐**！

### 1. 去差法（削平大数，求小数）
我们画出两条线段：大数长一点，小数短一点。
大数比小数多出了红色的那一段“差”：

```
大数: [==== 相同的一份 ====][-- 差值 --]  \
                                           } 和 (总数)
小数: [==== 相同的一份 ====]               /
```

此时，我们拿起一把虚拟的剪刀，把大数多出的“差值”**一刀剪掉**！
- 剪掉后，总数变成了：$\text{和} - \text{差}$；
- 剩下的两条线段，**完全一模一样长**，正好是 2 个“小数”！

因此，顺理成章：
$$\text{小数} = \frac{\text{和} - \text{差}}{2}, \quad \text{大数} = \text{小数} + \text{差}$$

### 2. 补差法（填齐小数，求大数）
如果我们不剪，而是拿出一块和差值一模一样大的木块，**贴到小数的屁股后面**：
- 填齐后，小数变得和大数一样长了；
- 此时的总数变成了：$\text{和} + \text{差}$；
- 这两条线段合在一起，正好是 2 个“大数”！

因此：
$$\text{大数} = \frac{\text{和} + \text{差}}{2}, \quad \text{小数} = \text{大数} - \text{差}$$

## 核心图景二：和倍与差倍（找准核心“一份量”）

到了和倍与差倍问题，解题的核心秘密就是三个字：**一份量**！
永远把那个**较小的量看作 1 份（1 个基础格子）**！

### 1. 和倍问题（已知总和与倍数）
较小量是 1 份，较大量是 $k$ 份。
把它们排在一起：
$$\text{总份数} = 1 + k$$
总和对应着 $(1 + k)$ 份，所以每一个格子的价值（一份量）就是：
$$\text{一份量 (小数)} = \frac{\text{和}}{1 + k}$$

```
小数 (1份):   [ 格子1 ]
大数 (3份):   [ 格子1 ][ 格子2 ][ 格子3 ]
合起来一共有: 1 + 3 = 4 个格子！
```

### 2. 差倍问题（已知相差与倍数）
较小量是 1 份，较大量是 $k$ 份。
较大量比较小量**足足多出了 $(k - 1)$ 份**！
而题目中给出的“差”，正好严丝合缝对应着这多出来的 $(k - 1)$ 份！

```
小数 (1份):   [ 格子1 ]
大数 (4份):   [ 格子1 ] | [ 格子2 ][ 格子3 ][ 格子4 ]  <-- 多出 3 份！
                        | ◀────── 相差 27 ──────▶ |
```
3 份对应 27，每份就是 $27 \div 3 = 9$！
$$\text{一份量 (小数)} = \frac{\text{差}}{k - 1}$$

## 家长辅导三步法（3-Step Inquiry）

当孩子面对和差倍应用题读不懂题时，千万别急着报算式，请按照这三步引导：

1. **第一步（动手指画线段）：**  
   “请在草稿纸上画两根长短不一的薯条：哪一根是大数，哪一根是小数？多出来的那一段写上数字几？”（逼孩子把文字翻译成图形）
2. **第二步（找齐平基准）：**  
   “你想把多出来的切掉（和减差），还是给短的补齐（和加差）？切掉后剩下几个短薯条？”（让孩子亲口说出“剩下 2 个小数，所以要除以 2”）
3. **第三步（数倍数格子）：**  
   “如果是倍数题，把小的画成 1 个方块，大的画成几个方块？差值对应了几个空方块？”（自然推导出除以 $k-1$）
