# 几何五大模型之“燕尾模型”：两翼面积与底边线段比

在小学中高年级（五、六年级）的平面几何竞赛与小升初压轴题中，**“几何五大模型”**（等积变形模型、鸟头模型、梯形蝴蝶模型、燕尾模型、沙漏模型）是每一位冲刺名校学生必须拿下的核心武器。

如果说“蝴蝶模型”是梯形与沙漏的化身，那么**“燕尾模型（Swallowtail Model）”**就是**普通任意三角形内比例转移的最强法宝**！

很多孩子看到下面这幅图时常常感到无从下手：
> 在 $\triangle ABC$ 内部随便点了一个点 $O$，连结 $AO$ 延长交底边于 $D$，连结 $BO, CO$。图被切成了好几个互不规则的碎块，题目问 $BD:CD$ 和面积有什么关系？

今天，我们将带孩子像解剖一只飞燕一样，用“大等高、小等高、大减小”三步推导，彻底看懂燕尾模型的精妙算理！

---

## 一、为什么它叫“燕尾模型”？

观察图形中的色块分布：

```
                   A (鸟头)
                  / \
                 /   \
                /  O  \  (内心分点)
               /  / \  \
              /  /   \  \
             /  /     \  \
            B ─── D ─── C
            └─BD─┘└──CD──┘
```

- $\triangle ABO$：左侧展开的一只翅膀（**左翼** $S_1$）；
- $\triangle ACO$：右侧展开的一只翅膀（**右翼** $S_2$）；
- 中间 $AO$ 延长到 $D$：贯穿整只燕子身体与尾羽的分界脊梁骨；
- 这两只翅膀在图形下方叉开，活脱脱像一只展翅掠水的小燕子的**分叉尾巴**，因而得名**燕尾模型**！

**燕尾模型黄金定理**：
$$\frac{S_{\triangle ABO}}{S_{\triangle ACO}} = \frac{BD}{CD}$$
> **口诀**：**左翼比右翼，恒等底边比！**

---

## 二、三步动画推导：为什么两翼之比等于底边比？

孩子最容易犯的错误是死记公式，一到考试把线段 $BD$ 和 $CD$ 跟哪只翅膀对应给记反了。只要掌握了下面的三步割补法，一辈子都不会记错！

### 第 1 步：大三角形共顶等高
把视线拉远，观察整座大三角形：
- 观察 $\triangle ABD$ 和 $\triangle ACD$；
- 它们共同拥有同一个顶点 $A$，它们的底边 $BD$ 和 $CD$ 在同一条直线 $BC$ 上；
- 从顶点 $A$ 到底边 $BC$ 作一条高线，这条高对两个三角形来说是**完全相同**的！
- 根据小学最基础的三角形面积公式（$S = \frac{1}{2} \times \text{底} \times \text{高}$）：
  $$\frac{S_{\triangle ABD}}{S_{\triangle ACD}} = \frac{BD}{CD}$$

---

### 第 2 步：底座小三角形共顶等高
现在把视线往下移，观察趴在底边上的小三角形：
- 观察 $\triangle OBD$ 和 $\triangle OCD$；
- 它们共同拥有同一个顶点 $O$，它们的底边依然是 $BD$ 和 $CD$；
- 从顶点 $O$ 到底边 $BC$ 作一条垂直高线，这条高对于 $\triangle OBD$ 和 $\triangle OCD$ 又是**完全相同**的！
- 再次得出：
  $$\frac{S_{\triangle OBD}}{S_{\triangle OCD}} = \frac{BD}{CD}$$

---

### 第 3 步：大减小，燕尾现！（等比差性质）
现在把第 1 步的大三角形，减去第 2 步的小三角形：
- 左边大块减左边小块：
  $$S_{\triangle ABD} - S_{\triangle OBD} = S_{\triangle ABO} \quad (\text{左翼})$$
- 右边大块减右边小块：
  $$S_{\triangle ACD} - S_{\triangle OCD} = S_{\triangle ACO} \quad (\text{右翼})$$

根据分数的**等比差性质**：如果 $\frac{a}{b} = \frac{c}{d} = k$，那么 $\frac{a - c}{b - d} = k$！
例如：$\frac{6}{9} = \frac{2}{3}$，那么 $\frac{6 - 2}{9 - 3} = \frac{4}{6} = \frac{2}{3}$！

两式相减，底座小三角形被完整扣除，左右两翼的面积比依然纹丝不动：
$$\frac{S_{\triangle ABO}}{S_{\triangle ACO}} = \frac{S_{\triangle ABD} - S_{\triangle OBD}}{S_{\triangle ACD} - S_{\triangle OCD}} = \frac{BD}{CD}$$
**推导完毕！优美至极！**

## 三、三向燕尾：三角形的“奔驰连比”

很多家长和孩子不知道，燕尾定理不仅可以在底边用，在三角形的**另外两条边上同样完全成立**！

如果过点 $O$ 把三条线段全部引向三边：
- $AO$ 的延长线交 $BC$ 于 $D$；
- $BO$ 的延长线交 $AC$ 于 $E$；
- $CO$ 的延长线交 $AB$ 于 $F$。

内部点 $O$ 将整个大三角形平分成了三块“大扇叶”（就像奔驰汽车的车标）：
- 上左块：$S_{\triangle ABO}$
- 上右块：$S_{\triangle ACO}$
- 下方块：$S_{\triangle BCO}$

三条边上的分段比瞬间被三块面积锁死：
1. **底边分比**：$\frac{BD}{CD} = \frac{S_{\triangle ABO}}{S_{\triangle ACO}}$（底边看上左右两翼）
2. **右边分比**：$\frac{CE}{AE} = \frac{S_{\triangle BCO}}{S_{\triangle ABO}}$（右边看下与左上两翼）
3. **左边分比**：$\frac{AF}{BF} = \frac{S_{\triangle ACO}}{S_{\triangle BCO}}$（左边看右上与下两翼）

一旦掌握了三向燕尾，遇到小升初“已知边长比例求内部面积”或“已知面积求线段比”的大题，**直接列连比，10 秒内口算秒杀**！

## 四、小升初经典压轴真题实战

> **【真题】**：
> 在 $\triangle ABC$ 中，$D$ 在 $BC$ 上，且 $BD : CD = 2 : 3$；$E$ 在 $AC$ 上，且 $AE : CE = 1 : 2$。
> $AD$ 与 $BE$ 相交于点 $O$。已知 $\triangle ABC$ 的总面积是 $60$。
> 求 $\triangle ABO$ 的面积。

### 秒杀思路（三向燕尾设未知数份数）：
1. 设三块核心燕尾的面积分别为：
   - $S_{\triangle ABO} = x$
   - $S_{\triangle BCO} = y$
   - $S_{\triangle ACO} = z$
2. 根据底边燕尾：$BD : CD = 2 : 3 \implies \frac{x}{z} = \frac{2}{3} \implies z = 1.5x$；
3. 根据右边燕尾：$AE : CE = 1 : 2 \implies \frac{x}{y} = \frac{1}{2} \implies y = 2x$；
4. 三块面积加起来等于总面积 60：
   $$x + y + z = x + 2x + 1.5x = 4.5x = 60$$
   $$x = 60 \div 4.5 = \frac{40}{3}$$
答案轻松得出！无需作任何一条复杂的垂直高线，全靠面积份数代数消元搞定！

2. **第二步（大减小游戏）**：“大三角形等高，底边比几比几，大三角形面积就几比几；把底下的小肚子剪掉，两只翅膀的面积比依然等于底边比！”
3. **第三步（口诀锁定）**：“记住八字金句：‘左翼比右翼，等于底边比’！做题时找到分界线，两只翅膀直接对准底边线段！”
