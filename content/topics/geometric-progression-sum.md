### 一个让古代国王倾家荡产的“不起眼”要求

相传在古印度，宰相西萨发明了国际象棋，国王大喜过望，许诺可以赏赐他任何想要的宝物。
聪明的西萨指着 64 格的棋盘平静地提出：
> “陛下，请在第 1 个格子里放 $1$ 粒麦子；第 2 个格子里放 $2$ 粒；第 3 个格子里放 $4$ 粒；第 4 个格子里放 $8$ 粒……**每一格放的麦粒都是前一格的 2 倍**，直到把 64 个格子全部摆满，将这些麦子赏给我就足够了。”

国王哈哈大笑，认为这不过是区区几袋粮食。
然而，当王宫的数学官算完全部总数后，国王却当场冷汗直流：
$$S = 1 + 2 + 4 + 8 + 16 + \dots + 2^{63} = 2^{64} - 1 \approx \mathbf{1844\text{ 亿亿粒麦子}}$$
把全世界所有的粮仓全部清空，连它的一小半都拿不出来！

这种**后一项与前一项的比值永远恒定**的数列，就叫做**等比数列（Geometric Progression）**。

### 第一代数神器：错位相减法（两式一减消灭全场）

面对长长的等比数列相加，逐个死加是不可能的。数学家发明了极其霸道的解法——**“错位相减法”**！

#### 示例演练：求 $S = 1 + 2 + 4 + 8 + 16 + 32 + 64 + 128$
1. **写出原式**：
   $$S = 1 + 2 + 4 + 8 + 16 + 32 + 64 + 128$$
2. **两边同乘公比 $q = 2$**：
   每一个数都被放大 2 倍，向后平移了一位：
   $$2S = 2 + 4 + 8 + 16 + 32 + 64 + 128 + 256$$
3. **两式上下错位相减**：
   $$\begin{aligned}
   2S &= \quad 2 + 4 + 8 + 16 + 32 + 64 + 128 + 256 \\
   -\quad S &= 1 + 2 + 4 + 8 + 16 + 32 + 64 + 128 \\
   \hline
   (2 - 1)S &= 256 - 1
   \end{aligned}$$
   中间从 2 到 128 的所有数字**全部被扣成 0 灰飞烟灭**！
4. **一秒出解**：
   $$S = 256 - 1 = \mathbf{255}$$

#### 通用等比数列求和公式：
$$S_n = \frac{a_1(q^n - 1)}{q - 1} \quad (q \neq 1)$$

### 第二几何直观：正方形折半拼图（无穷收敛至 1）

在小升初的计算题中，更常见的是**分数等比数列**：
$$S = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{16} + \frac{1}{32} + \dots + \frac{1}{2^n}$$

#### 几何折半拼图法（无需通分）：
拿出一张面积为 $1$ 的完整大正方形：
1. 第一次对半切，取走左半边 $\frac{1}{2}$，**剩下 $\frac{1}{2}$ 没取**；
2. 在剩下的半边里再切一半，取走 $\frac{1}{4}$，**剩下 $\frac{1}{4}$ 没取**；
3. 在剩下的四分之一里再切一半，取走 $\frac{1}{8}$，**剩下 $\frac{1}{8}$ 没取**；
4. 依此类推，无论你切了多少次，**所有取走的面积之和，永远等于“整块面积 1”减去“最后剩下的一小块空白”**！

$$\mathbf{\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \dots + \frac{1}{2^n} = 1 - \frac{1}{2^n}}$$

- 如果加到 $\frac{1}{64}$：$S = 1 - \frac{1}{64} = \frac{63}{64}$；
- 如果加到 $\frac{1}{1024}$：$S = 1 - \frac{1}{1024} = \frac{1023}{1024}$！
用几何面积的留白思维，任何复杂的指数连续通分瞬间变成口算！
