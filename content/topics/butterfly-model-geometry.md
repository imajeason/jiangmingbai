### 为什么说“蝴蝶模型”是小学几何的第一把屠龙刀？

在小学五年级和六年级的小升初数学几何压轴题中，经常会遇到这样一类图形：
一个梯形，两条对角线交叉，把整个梯形分割成了 4 个小三角形。

```text
       A ─────── D      (上底 a)
        \       /
         \  O  /
          \   /
     B ─────┴───── C    (下底 b)
```

这个图案极像一只张开翅膀翩翩起舞的蝴蝶：
- 上面的小三角形 $S_1$ 是蝴蝶的“头”；
- 下面的大三角形 $S_2$ 是蝴蝶的“尾巴”；
- 左右两侧的两个三角形 $S_3$ 和 $S_4$，正好是蝴蝶的一对“翅膀”！

考卷上几乎所有的压轴大题，都围绕这 4 块面积展开。许多孩子死记公式却总在“开平方”或“乘积对应”上混淆。
只要看透**“同底等高去公共角”**与**“沙漏相似比”**两大核心推导，整套几何蝴蝶模型将变得无比直观自然！

### 第一步：秒杀灵魂——为什么左右两只“翅膀”面积一定绝对相等？

很多孩子做题时不敢相信：**“左边的梯形腰斜一点，右边的腰直一点，两只翅膀面积真的一模一样大吗？”**

答案是：**无论梯形怎么歪、怎么扁，两只翅膀的面积必定 100% 绝对相等（$S_3 = S_4$）！**

#### 极简三步推导法：
1. **看左侧大三角形 $\triangle ABC$**：
   - 底是梯形的下底 $BC$；
   - 高是平行线 $AD$ 与 $BC$ 之间的垂直距离 $h$；
   - 面积：$S(\triangle ABC) = \frac{1}{2} \times BC \times h$。
2. **看右侧大三角形 $\triangle DBC$**：
   - 底同样是梯形的下底 $BC$；
   - 顶点 $D$ 在平行线 $AD$ 上，所以高依然是完全相同的垂直距离 $h$！
   - 面积：$S(\triangle DBC) = \frac{1}{2} \times BC \times h$。
   - **由此可知：两座大三角形面积完全相等：$S(\triangle ABC) = S(\triangle DBC)$！**
3. **两边同时剪掉公共底角 $\triangle OBC$**：
   - 左大三角减去公共角：$S(\triangle ABC) - S(\triangle OBC) = S_3$（左翅膀）；
   - 右大三角减去公共角：$S(\triangle DBC) - S(\triangle OBC) = S_4$（右翅膀）；
   - **因为原面积相等，减去相同的部分，差依然相等！**

$$\mathbf{S_3 = S_4 \quad (\text{两只蝴蝶翅膀面积必相等！})}$$

### 第二步：对顶乘积定理——为什么 $S_1 \times S_2 = S_3 \times S_4$？

不仅两只翅膀相等，梯形内这 4 块面积之间还有一个极其优美的恒等关系：
**上下两块的乘积，永远等于左右两只翅膀的乘积！**

$$S_1 \times S_2 = S_3 \times S_4 = S_3^2$$

#### 推导逻辑（高之比与底之比）：
- 观察 $\triangle AOD$（$S_1$）和 $\triangle AOB$（$S_3$）：它们共享顶点 $A$，底边都在对角线 $BD$ 上。
  因此它们的面积之比，就等于线段之比：
  $$\frac{S_1}{S_3} = \frac{OD}{OB}$$
- 再观察 $\triangle DOC$（$S_4$）和 $\triangle BOC$（$S_2$）：它们共享顶点 $C$，底边也都在对角线 $BD$ 上。
  它们的面积之比，同样等于相同的线段之比：
  $$\frac{S_4}{S_2} = \frac{OD}{OB}$$
- 将两式联立：
  $$\frac{S_1}{S_3} = \frac{S_4}{S_2} \implies S_1 \times S_2 = S_3 \times S_4$$
- 又因为两只翅膀面积相等（$S_3 = S_4$），所以：
  $$S_1 \times S_2 = S_3^2 \implies \mathbf{S_3 = S_4 = \sqrt{S_1 \times S_2}}$$

> 💡 **考场绝杀：**  
> 题目只要给出上下两块的面积，**将它们相乘再开平方**，就能立刻秒算出单只翅膀的面积！

### 第三步：沙漏模型——上下对顶相似三角形的平方定律

当梯形上底为 $a$、下底为 $b$ 时，中间的交点 $O$ 将两条对角线分割：
上面的 $\triangle AOD$ 与下面的 $\triangle BOC$ 构成了一个经典的**沙漏形状**：

```text
       A ─────── D       (底为 a)
          \  O  /
     B ─────┴───── C     (底为 b)
```

1. **线段比**：
   $$\frac{AD}{BC} = \frac{AO}{OC} = \frac{DO}{OB} = \frac{a}{b}$$
2. **高之比**：
   上三角形的高 $h_1$ 与下三角形的高 $h_2$ 之比也是 $\frac{a}{b}$；
3. **面积之比（相似比的平方）**：
   $$\frac{S_1}{S_2} = \left(\frac{a}{b}\right)^2 = \frac{a^2}{b^2}$$

#### 蝴蝶模型面积四份数黄金比：
如果设基础份数，则 4 块面积的份数比例为：
$$\mathbf{S_1 : S_2 : S_3 : S_4 = a^2 : b^2 : ab : ab}$$

梯形的总面积份数正好是一个完美的完全平方公式：
$$S_{\text{总}} = a^2 + b^2 + 2ab = \mathbf{(a + b)^2}$$

### 课后小测验与实战解析

> **经典挑战题：**  
> 在一个梯形 ABCD 中，AD 平行于 BC，对角线 AC 与 BD 交于点 O。  
> 已知上部 $\triangle AOD$ 的面积为 $4 \text{ cm}^2$，下部 $\triangle BOC$ 的面积为 $9 \text{ cm}^2$。  
> 求：  
> 1. 左右两只翅膀 $\triangle AOB$ 和 $\triangle DOC$ 的面积各是多少？  
> 2. 整个梯形 ABCD 的总面积是多少？

**详细解题剖析：**

1. **第一问（求翅膀面积）：**  
   - 由对顶乘积定理：$S_3 \times S_4 = S_1 \times S_2$；  
   - 又因为两只翅膀相等 $S_3 = S_4$；  
   - 所以：
     $$S_3 = S_4 = \sqrt{4 \times 9} = \sqrt{36} = \mathbf{6 \text{ cm}^2}$$  
   - 左右两只翅膀面积各自为 $6 \text{ cm}^2$。

2. **第二问（求梯形总面积）：**  
   - **方法一（四块直接求和）：**  
     $$S_{\text{梯形}} = S_1 + S_2 + S_3 + S_4 = 4 + 9 + 6 + 6 = \mathbf{25 \text{ cm}^2}$$  
   - **方法二（完全平方式秒杀）：**  
     $$S_{\text{梯形}} = (\sqrt{S_1} + \sqrt{S_2})^2 = (\sqrt{4} + \sqrt{9})^2 = (2 + 3)^2 = 5^2 = \mathbf{25 \text{ cm}^2}$$
