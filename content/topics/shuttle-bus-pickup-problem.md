### 华杯赛与小升初分班考的“压轴常青树”

在各大数学竞赛和重点中学分班考试中，有一类题目几乎每年都会换个马甲压轴登场——**“校车接送问题”**：
> 某学校组织两队学生（甲队和乙队）去 $100\text{ km}$ 外的夏令营基地。
> 学校只有一辆校车，一次只能乘坐一队学生。
> - 校车的行车速度为 $40\text{ km/h}$；
> - 学生的步行速度为 $8\text{ km/h}$。
> 
> 两队学生与校车同时从学校出发。为了让所有学生**在最短的时间内全部到达基地**，校车该如何接送？**全体到达基地的最短时间是多少小时？**

看到题目，很多孩子一片茫然：
- 校车到底应该开到全程的什么位置把甲队放下？
- 掉头回去接乙队时，是在哪里和乙队相遇？
- 变量有时间、两处距离、三次行程，根本无从下手。

这道题之所以高级，是因为它将**“运筹学资源优化”**与**“行程速度比方程”**完美熔于一炉！

### 第一破局武器：两大不容置疑的最优对称原则

#### 1. 原则一：全员必须【同时到达】！
为什么？
- 如果甲队比乙队先到：说明校车送甲队送得太远了，车在空车往返期间，乙队在后方徒步受苦，总时间必然被拖长；
- 只有当**甲队徒步冲过终点线的同时，校车正好载着乙队也冲过终点线**，没有任何人提前闲等，效率才达到数学理论极限！

#### 2. 原则二：两队步行距离【严格对称相等】！
两队学生步行速度相同（都是 $8\text{ km/h}$），乘车速度相同（都是 $40\text{ km/h}$），且同时出发、同时到达：
- **甲队徒步的总距离 = 乙队徒步的总距离 = $x$**；
- **甲队乘车的总距离 = 乙队乘车的总距离 = $S - x$**！

### 第二破局武器：画出时空折线，锁定车人路程比

设总路程 $S = 100\text{ km}$，每队徒步距离为 $x$。
让我们跟随时间线观察关键节点：

```
起点(学校)                     相遇点D            下车点C          终点(营地)
  0 ───────────────────────────── x ────────────── S-x ─────────────── S
  │                             ▲                 ▲                   │
  ├─ 乙队徒步前进至 x ───────────┤                 │                   │
  └─ 校车送甲队至 S-x ────────────────────────────┴─ 甲队徒步前进至S ─┘
     校车掉头返回 D 接乙队 ───────┘
```

#### 关键时钟窗口：从【出发】到【校车掉头接上乙队】
在这同一段时间内：
1. **乙队的运动轨迹**：
   从起点步行到了相遇点 $D$，**步行路程 $= x$**；
2. **校车的运动轨迹**：
   - 先送甲队到 $C$ 点，行驶路程为：$S - x$；
   - 掉头开回 $D$ 点接乙队，掉头返程距离为：$C$ 到 $D$ 的距离 $= (S - x) - x = S - 2x$；
   - **校车行驶总路程** $= (S - x) + (S - 2x) = \mathbf{2S - 3x}$！

#### 列出速度路程比方程：
因为时间和车人同时，**车走的总路程与人走的总路程之比，严格等于车速与人速之比**：
$$\frac{\text{校车总路程}}{\text{乙队总路程}} = \frac{v_{\text{车}}}{v_{\text{人}}}$$
$$\frac{2S - 3x}{x} = \frac{40}{8} = 5$$

解这个简单的一元一次方程：
$$2S - 3x = 5x \implies 8x = 2S \implies \mathbf{x = \frac{1}{4}S}$$

### 答案水落石出，秒杀真题

1. **求徒步与乘车距离**：
   - 每队徒步距离 $x = \frac{1}{4} \times 100 = \mathbf{25\text{ km}}$；
   - 每队乘车距离 $S - x = 100 - 25 = \mathbf{75\text{ km}}$；
   - 换句话说：**校车把甲队送到 $75\text{ km}$ 处放下，甲队徒步剩下的 $25\text{ km}$；校车掉头在 $25\text{ km}$ 处接上乙队直奔终点！**
2. **求全体到达的最短总时间**：
   以甲队的一生为例（乘车 $75\text{ km}$，步行 $25\text{ km}$）：
   $$t_{\text{总}} = \frac{75\text{ km}}{40\text{ km/h}} + \frac{25\text{ km}}{8\text{ km/h}} = 1.875\text{ 小时} + 3.125\text{ 小时} = \mathbf{5\text{ 小时}}！$$

对比如果全员单靠双腿走需要 $100 \div 8 = 12.5$ 小时；通过校车对称接驳，耗时被硬生生压缩到了 **5 小时**！华杯赛压轴题，四步之内彻底解剖！
