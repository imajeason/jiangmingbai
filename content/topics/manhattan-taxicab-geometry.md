# 曼哈顿出租车几何：折线距离与菱形圆周的非欧空间初体验

## 一、鸟与出租车的较量

假设你在棋盘式规划的纽约曼哈顿市区，想从十字路口 $A(1, 1)$ 前往路口 $B(4, 5)$：
- **如果是一只小鸟（欧几里得几何）**：
  小鸟展翅高飞，在空中两点之间直接沿着斜直线飞过去。根据勾股定理，鸟飞过的直线距离是：
  $$d_{\text{Euclid}} = \sqrt{(4 - 1)^2 + (5 - 1)^2} = \sqrt{3^2 + 4^2} = 5$$！
- **但如果你是坐在地面上的出租车（曼哈顿几何）**：
  出租车不能像小鸟一样从高楼大厦上直接穿透飞过去！它必须严格沿着城市的道路网络行进：要么横向东西开，要么纵向南北开。
  因此，出租车必须行驶的实际距离是：
  $$d_{\text{Taxicab}} = |4 - 1| + |5 - 1| = 3 + 4 = 7$$！

这种**只允许沿着正交网格轴线方向测量的距离**，在数学上被称为**曼哈顿距离（Manhattan Distance）**，或者**出租车度量（Taxicab Metric / $L_1$ 范数）**。

## 二、颠覆常识的曼哈顿几何三大奇观

当你戴上“出租车墨镜”进入曼哈顿世界时，传统平面几何中几乎所有公理都被彻底改写！

### 奇观一：两点之间，“最短路径”不再唯一！
在欧氏几何中，“两点之间线段最短”并且这条最短线段**有且仅有一条**。
但在曼哈顿几何中：
- 从 $(1, 1)$ 到 $(4, 5)$，最短距离是 $7$；
- 你可以先向东开 3 格再向北开 4 格（距离 7）；
- 也可以先向北开 4 格再向东开 3 格（距离 7）；
- 甚至可以像台阶一样曲折向前开（横 1 $\to$ 竖 2 $\to$ 横 2 $\to$ 竖 2，距离依然是 7）！
- 凡是不走回头路的所有“楼梯路径”，长度全部完全相同，并且都达到最短！
- 总共有多少条不同的最短路径？根据组合计数，恰好有：
  $$\binom{3 + 4}{3} = \binom{7}{3} = \frac{7 \times 6 \times 5}{3 \times 2 \times 1} = 35 \text{ 条不同的最短路线！}$$

---

### 奇观二：曼哈顿世界里的“圆”居然是一个正方形！
在数学中，“圆”的唯一定义是：**平面上到定点（圆心）距离等于定长（半径 $R$）的所有点的集合！**

在曼哈顿世界中，设圆心为原点 $(0, 0)$，半径为 $R$。
那么圆上的所有点 $(x, y)$ 必须满足：
$$|x| + |y| = R$$
让我们找几个满足条件的点：
- 当 $x = R$ 时，$y = 0 \implies (R, 0)$；
- 当 $x = 0$ 时，$y = R \implies (0, R)$；
- 当 $x = -R$ 时，$y = 0 \implies (-R, 0)$；
- 当 $x = 0$ 时，$y = -R \implies (0, -R)$；
- 在第一象限中，$x + y = R$，这是一条连接 $(R, 0)$ 和 $(0, R)$ 的倾斜 $45^\circ$ 的线段！

把所有这些点连起来，呈现在眼前的竟然是一个**倾斜了 $45^\circ$ 的菱形正方形**！
**在出租车的眼里，这个正方形就是百分之百货真价实的“圆”！因为正方形边界上的每一个点，距离市中心的打车路程都分毫不差，严格等于 $R$！**

---

### 奇观三：曼哈顿圆周率 $\pi_{\text{Taxicab}} = 4$！
我们知道圆周率 $\pi$ 的定义是“圆周长与直径之比”：
$$\pi = \frac{C}{2R}$$
在这个曼哈顿正方形圆中：
1. 直径显然是两端点之间的出租车距离：$2R$；
2. 算一算这个“圆”的周长：
   正方形在第一象限的这条边，从 $(R, 0)$ 走到 $(0, R)$，出租车距离是：
   $$|R - 0| + |0 - R| = 2R$$！
3. 正方形共有 4 条边，整个曼哈顿圆的周长为：
   $$C = 4 \times 2R = 8R$$！
4. 计算曼哈顿圆周率：
   $$\pi_{\text{Taxicab}} = \frac{C}{2R} = \frac{8R}{2R} = \mathbf{4}$$！
**在这个奇妙的几何世界中，圆周率不再是神秘的无理数 $3.1415926\dots$，而是干脆利落的整数 $4$！**

## 三、经典例题解析

### 例题一：三角形不等式检验
> **题目**：平面上有三点 $A(0, 0), B(3, 0), C(3, 4)$。
> 检验在曼哈顿距离下，是否满足 $d(A, C) \le d(A, B) + d(B, C)$？
>
> **解析**：
> 1. $d(A, B) = |3 - 0| + |0 - 0| = 3$；
> 2. $d(B, C) = |3 - 3| + |4 - 0| = 4$；
> 3. $d(A, C) = |3 - 0| + |4 - 0| = 3 + 4 = 7$；
> 4. 算式：$d(A, B) + d(B, C) = 3 + 4 = 7 = d(A, C)$！
> 5. 结论：在曼哈顿世界中，三角形两边之和可以**严格等于第三边**（不仅大于）！

---

### 例题二：出租车平分线问题
> **题目**：在曼哈顿世界中，到 $A(-1, 0)$ 和 $B(1, 0)$ 距离相等的点的轨迹是什么？
>
> **解析**：
> - 满足 $|x + 1| + |y| = |x - 1| + |y|$；
> - 两边消去 $|y|$，得到 $|x + 1| = |x - 1| \implies x = 0$；
> - 轨迹为 $y$ 轴（与欧氏几何重合）。但若两点呈对角倾斜，其中垂线将不再是一条直线，而是一整个二维区域面！
