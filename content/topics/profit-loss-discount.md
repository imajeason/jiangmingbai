# 经济利润问题：进价、标价、打折与利润率

在小学六年级数学中，“百分数应用题”是应用题模块的集大成者。其中，与我们日常生活最贴近、考场上失分率极高的，当属**“经济利润与打折问题”**。

很多孩子在学完这一章后，脑子里全是浆糊：
> “标价和售价到底有什么区别？打八折是乘以 0.8 还是除以 0.8？算利润率的时候，分母为什么除以进价而不是除以售价？一件衣服先涨 20% 又降 20%，加减抵消怎么可能还会亏钱？”

今天，我们带孩子化身“精明小掌柜”，用一幅清晰的商业流水线图，把所有价格、利润率与促销套路彻底算个明明白白！

---

## 一、商业四部曲：进价、标价、售价与利润

要学好利润问题，首先必须把四个名词严格区分清楚，千万不能混为一谈：

```
       采购成本                贴上标签               顾客砍价/促销            算账分红
   ┌──────────────┐       ┌──────────────┐       ┌──────────────┐       ┌──────────────┐
   │ ① 进价/成本 │  ──►  │ ② 标价/原价 │  ──►  │ ③ 实际售价  │  ──►  │ ④ 纯利润    │
   │ (老板掏腰包) │ 加价  │ (吊牌上的字) │ 打折  │ (收银台刷卡) │ 扣本  │ (真正落袋)   │
   └──────────────┘       └──────────────┘       └──────────────┘       └──────────────┘
```

### 1. 进价（成本 $C$）
商家去工厂或批发市场采购商品所花费的本钱。这是整个商业交易的**基石**，也是计算投资收益的**唯一基准单位“1”**。

### 2. 标价（原价 / 门市价 $M$）
商品摆在货架上，吊牌上印的价格。商家通常会在进价的基础上上浮一定比例：
$$\text{标价} = \text{进价} \times (1 + \text{加价率})$$
例如：成本 100 元，加价 50% 标价，标价就是 $100 \times (1 + 50\%) = 150$ 元。

### 3. 实际售价（现价 $P$）
商场举行促销活动，或者顾客使用优惠券后，**在收银台实际刷卡支付的金额**。
“几折”就代表售价是标价的“十分之几”或“百分之几十”：
$$\text{售价} = \text{标价} \times \frac{\text{折数}}{10} = \text{标价} \times \text{折扣百分比}$$
例如：标价 150 元，打八折（80%）出售，实际售价就是 $150 \times 0.8 = 120$ 元。

### 4. 利润（$L$）与利润率（$r$）
卖完商品收回钱后，先还掉采购本钱，剩下多出来的才是商家的纯收入：
$$\text{利润} = \text{实际售价} - \text{成本进价}$$
- 如果售价 > 进价：盈利（赚了）；
- 如果售价 < 进价：亏损（亏本）。

## 二、第一号致命陷阱：利润率的分母到底除以谁？

在考场上，有 40% 的孩子在计算利润率时会写错分母：
> 错误做法：$\text{利润率} = \frac{\text{利润}}{\text{售价}} \times 100\%$ （❌ 大错特错！）

### 为什么必须除以“进价成本”？
**利润率是用来衡量“本钱的赚钱能力”（投资回报率）的！**
- 比如你投资了 100 块钱，最后净赚了 20 块钱，说明你的本钱获得了 $20\%$ 的增值收益；
- 所以，在中小学数学教学体系中，**利润率的基准单位“1”永远且绝对是【进价成本】**！

$$\text{利润率} = \frac{\text{利润}}{\text{进价成本}} \times 100\% = \frac{\text{售价} - \text{进价}}{\text{进价}} \times 100\%$$

由该公式还可直接推导逆向公式：
$$\text{售价} = \text{进价} \times (1 + \text{利润率})$$
$$\text{进价} = \frac{\text{售价}}{1 + \text{利润率}}$$

## 三、第二号致命陷阱：“先涨 20%，再降 20%”，为什么亏了 4%？

这是中考、小升初和奥数中屡试不爽的经典“钓鱼题”：
> **题目**：某品牌球鞋原价 100 元，店庆时先提价 20%，随后又降价 20% 促销。请问：现在的价格和原价相比，是涨了、降了，还是没变？

很多孩子想都不想就脱口而出：
> “先加 20%，又减 20%，一加一减相互抵消，肯定还是 100 元不变啊！”

**大错特错！** 让我们一步步列式观察：

1. **第一步（先涨价 20%）**：
   - 此时的基准单位“1”是 **原价 100 元**；
   - 提价后的金额：$100 \times (1 + 20\%) = 120$ 元（增加了 **+20 元**）。
2. **第二步（再降价 20%）**：
   - 重点来了！现在的降价是在 **涨价后的 120 元** 基础上打折！
   - 此时的基准单位“1”已经悄悄变成了 **120 元（变大了！）**；
   - 降价扣除的金额是：$120 \times 20\% = 24$ 元（扣除了整整 **-24 元**！）；
   - 最终现价：$120 - 24 = 96$ 元！

3. **对比结果**：
   - 原价 100 元，现价 96 元！
   - 商家**白白亏损了 4 元（亏了 4%）**！

```
     初始: 100 元
      │
      ├─► 涨 20% (基于 100 涨) ──► 变 120 元 (+20 元)
      │
      └─► 降 20% (基于 120 降) ──► 变 96 元  (-24 元)
          ────────────────────────────────────────────
          净结果: 100 - 96 = 亏损 4 元 (亏损 4%)！
```

### 极速通用公式：
如果一个商品先涨 $a\%$，再降 $a\%$（或者先降 $a\%$ 再涨 $a\%$）：
$$\text{现价} = \text{原价} \times (1 + a\%) \times (1 - a\%) = \text{原价} \times (1 - a\%^2)$$
只要 $a > 0$，最终价格**必定恒小于原价**，且亏损率永远等于 **$(a\%)^2$**！
- 涨跌 10%：$1 - 10\%^2 = 1 - 1\% = 99\%$（亏 1%）；
- 涨跌 20%：$1 - 20\%^2 = 1 - 4\% = 96\%$（亏 4%）；
- 涨跌 30%：$1 - 30\%^2 = 1 - 9\% = 91\%$（亏 9%）。

## 四、生活中的数学：超市促销哪家强？

在超市购物时，面对不同的促销方案，哪种真正最划算？
假设你要买价值 240 元的物品：

| 促销方案 | 实际支付 | 折算实际折扣 | 优劣分析 |
| :--- | :--- | :--- | :--- |
| **方案 A：全场 75 折** | $240 \times 0.75 = 180$ 元 | **7.5 折** | 门槛低，买多少都稳赚 25% |
| **方案 B：每满 200 减 50** | $240 - 50 = 190$ 元 | **7.9 折** | 刚好超过 200 元时最吃亏；若刚好买 200 元实付 150 元才等价于 75 折 |
| **方案 C：买四赠一** | 相当于付 4 件得 5 件：$\frac{4}{5} = 80\%$ | **8.0 折** | 恒定等于 8 折，适合大批量消耗品囤货 |

## 五、亲子互动 3 步走引导清单

1. **第一步（分清四个角色）**：“宝贝，进价是本钱，标价是标签，售价是收银条，利润是到手赚的钱。这四个数千万别混掉！”
2. **第二步（抓牢分母是谁）**：“算利润率，是看本钱翻了多少倍，所以分母必须是最初掏腰包的进价！”
3. **第三步（揭穿涨跌陷阱）**：“先涨后降为什么亏钱？因为涨价是在小钱上加，降价是在大钱上扣，扣得多加得少，最终肯定亏！”
