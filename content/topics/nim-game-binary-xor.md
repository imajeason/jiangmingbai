### 改变世界博弈论历史的古老游戏

在世界各地的古老传说中，流传着一种捡石子（或拿火柴）的智力决斗：
> **桌上有几堆火柴（例如 3 堆，数量分别为 3 根、4 根、5 根）。**
> **甲、乙两人轮流拿火柴，游戏规则极其简单：**
> 1. **每次必须且只能从“其中某一堆”里拿走火柴；**
> 2. **拿取的数量不限，至少拿 1 根，也可以一口气把整堆全部拿光；**
> 3. **谁拿走桌上最后一根火柴，谁就获得最终的胜利（普通制）！**

在长达数百年的时间里，人们一直以为这只是个纯粹靠算力和直觉拼杀的游戏。
直到 1901 年，美国哈佛大学数学家**查尔斯·鲍顿（Charles Bouton）**发表了一篇震撼数学界的论文，不仅用严密的数学公式彻底破解了这个游戏，还将其正式命名为**“尼姆博弈（Nim Game）”**！

### 从“两堆火柴”发现对称镜像法则

在挑战三堆之前，我们先看两堆火柴的情形：
- **两堆数量相等（如 3 根和 3 根）**：
  后手具有**“绝对必胜镜像策略”**！
  只要先手在 A 堆拿 $x$ 根，后手就立刻在 B 堆也拿 $x$ 根！后手永远保持两堆数量完全一致。
  最后先手拿空某一堆，后手必定能一把拿空另一堆，赢得胜利！
- **两堆数量不等（如 3 根和 5 根）**：
  先手必胜！先手只要第一步从 5 根那堆里拿走 2 根，瞬间把局面变成 `(3, 3)` 的对称态丢给后手，自己化身成后手赢得胜利！

两堆火柴的核心是“对称相等”。但当变成**三堆甚至更多堆**时，“对称”变成了什么？

### 鲍顿的绝杀武器：二进制异或和（Nim-Sum）

鲍顿发现，多堆火柴的“对称平衡”，本质上隐藏在**二进制**中！

把每堆火柴的根数写成二进制：
- 堆 A = 3 $\implies$ 二进制：`0 1 1`
- 堆 B = 4 $\implies$ 二进制：`1 0 0`
- 堆 C = 5 $\implies$ 二进制：`1 0 1`

我们对它们进行**“不进位加法”（计算机中的“异或”运算，符号为 $\oplus$）**：
统计每一列二进制位上的“1”的总个数：
- 第 4 位列（$2^2$）：堆 B 有 1，堆 C 有 1 $\implies$ 一共有 2 个 1（偶数个，异或为 0）；
- 第 2 位列（$2^1$）：堆 A 有 1 $\implies$ 一共有 1 个 1（**奇数个**，异或为 1）；
- 第 1 位列（$2^0$）：堆 A 有 1，堆 C 有 1 $\implies$ 一共有 2 个 1（偶数个，异或为 0）。

计算结果：$3 \oplus 4 \oplus 5 = (010)_2 = \mathbf{2}$！这个值被称为**“尼姆和（Nim-Sum）”**。

### 黄金必胜定律：P 态与 N 态

在博弈论中，局面只有两种命运：

1. **必败态（P-position，Previous-player win 后手必胜态）**：
   $$\text{尼姆和 } S = 0$$
   - 此时每一列二进制上的“1”全部都是偶数个！
   - 无论谁在任何一堆拿走任何数量，**必定会破坏这一平衡**，导致异或和变成非零！
2. **必胜态（N-position，Next-player win 先手必胜态）**：
   $$\text{尼姆和 } S \neq 0$$
   - 此时至少有一列存在奇数个 1。
   - 数学已严格证明：**处于非零态的玩家，必定存在至少一种合法拿法，使各堆调整后的异或和精准变回 0！**

#### 实战复盘：(3, 4, 5) 局面的第一步绝杀走法
当前局面的尼姆和为 $2$（最高位 1 在第 2 列）。
我们只需在二进制第 2 位有 1 的那一堆（堆 A：3 根，二进制 011）中做手脚：
- 我们想让堆 A 变成 $3 \oplus 2 = 1$！
- 也就是说：**从第 A 堆里拿走 2 根火柴，让它只剩 1 根！**
- 此时局面变成：`1 根、4 根、5 根`！
- 检验新的尼姆和：$1 \oplus 4 \oplus 5 = (001)_2 \oplus (100)_2 \oplus (101)_2 = (000)_2 = \mathbf{0}$！
- 完美的平衡死局被扔给了对手，从此无论对手怎么拿，你只需重复“把异或和恢复为 0”，胜利便如探囊取物！
