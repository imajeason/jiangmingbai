### 为什么说短除法在“大质数”面前往往无能为力？

在小学四年级、五年级，我们学习了求最大公约数（GCD）的常规武器——**短除法（分解质因数）**：
- 比如求 $24$ 和 $36$ 的最大公约数：先除以 2 得 12 和 18，再除以 2 得 6 和 9，再除以 3 得 2 和 3，算得 $2 \times 2 \times 3 = 12$。

但到了五、六年级杯赛与小升初分班考中，题目突然升级为这样的大数：
> **请将分数 $\frac{319}{377}$ 化为最简分数！**

很多孩子在草稿纸上崩溃了：
- 尾数不是偶数，不能被 2 整除；
- 各数位和不为 3 的倍数（$3+1+9=13$）；
- 尾数不是 0 或 5；
- 试除 7：$319 \div 7 = 45 \dots 4$；
- 试除 11：$319 \div 11 = 29$，但 $377 \div 11 = 34 \dots 3$；
整整试了十几分钟，心态彻底崩溃。

早在公元前 300 年，古希腊数学家**欧几里得（Euclid）**在人类文明巨著《几何原本》第七卷中，就记录了一个无需任何试除的降维神技——**辗转相除法（Euclidean Algorithm）**！

### 第一几何直观：铺满长方形的“俄罗斯方块裁剪”

欧几里得最初并不是用数字除法来思考这个问题的，而是用纯粹的**几何拼砖**：
假设有一块长为 $377$、宽为 $319$ 的长方形地面，我们要用**边长最大的同规格正方形瓷砖**把它刚好铺满。

```
+-----------------------------------+-------+
|                                   |       |
|                                   |       |
|                                   |   58  |
|            319 × 319              |   ×   |
|                                   |  319  |
|                                   |       |
+-----------------------------------+-------+
                 377
```

1. **第一刀裁剪**：在长方形里裁出一个最大的正方形，边长为 $319$。
   - 裁完后，剩下了一个 $319 \times 58$ 的狭长长方形；
   - 核心逻辑：**能铺满大长方形的瓷砖，必定也必须能铺满剩下的这个小长方形！**
2. **第二刀裁剪**：用 $58 \times 58$ 的正方形去铺这块 $319 \times 58$ 的地面。
   - $319 \div 58 = 5$（铺了 5 块），剩下的宽度为：
     $$319 - 58 \times 5 = \mathbf{29}$$
   - 此时剩下了一块 $58 \times 29$ 的迷你长方形！
3. **第三刀裁剪**：用 $29 \times 29$ 的正方形去铺 $58 \times 29$ 的地面。
   - $58 \div 29 = 2$（刚好铺 2 块，**完全铺满，余数为 0！**）。
4. **结案**：
   那块能够铺满整个大房间的最大瓷砖边长，正好就是 **29**！
   $$\gcd(377, 319) = \mathbf{29}$$

### 第二代数精髓：带余除法连环相除

把上面的几何铺地砖转换成纯数学竖式计算，只需短短三行：

$$\begin{aligned}
377 \div 319 &= 1 \quad \dots \quad \mathbf{58} \\
319 \div \mathbf{58} &= 5 \quad \dots \quad \mathbf{29} \\
\mathbf{58} \div \mathbf{29} &= 2 \quad \dots \quad \mathbf{0}
\end{aligned}$$

- 每次将**上一轮的除数**，拿来除以**上一轮的余数**；
- 当某一步算出的**余数恰好为 0** 时，**当前的除数就是最终的最大公约数**！

#### 回到原题化简分数：
$$\frac{319}{377} = \frac{319 \div 29}{377 \div 29} = \mathbf{\frac{11}{13}}$$
整个过程不超过 30 秒，完全不用苦苦猜测 29 这个冷门质数！

### 辗转相除法数学定理严格依据

为什么 $\gcd(a, b) = \gcd(b, a \bmod b)$？
设 $a = q \cdot b + r$，如果整数 $d$ 能同时整除 $a$ 和 $b$：
那么 $d$ 必然也能整除 $a - q \cdot b = r$！
反之，能整除 $b$ 和 $r$ 的数也必然能整除 $a$。
因此，**$(a, b)$ 的公约数集合，与 $(b, r)$ 的公约数集合完全一模一样！**
通过除法求余，数字迅速变小（至少缩小一半），无论多大的天文数字，通常在 5 步之内必然收敛出答案！
